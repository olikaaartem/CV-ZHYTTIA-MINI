CV ЖИТТЯ — настільний помічник

1. Розпакуйте весь архів у папку.
2. Відкрийте index.html у Chrome, Edge або Firefox на комп’ютері.
3. Оберіть 1–6 гравців, імена та персонажів.
4. Киньте кубик. Перетягніть фішку на клітинку або оберіть гравця в списку й натисніть клітинку.
5. Після зупинки відкриється випадкова картка відповідної категорії та кола.
6. Закрийте картку та натисніть «Завершити хід».

Перехід між колами: вручну поставте фішку на потрібну клітинку іншого кола.
На малому колі 28 клітинок, на великому — 56; категорії та спеціальні поля перенесено з основної гри.
Кубик лише показує число й орієнтир у поточному колі. Рух не обмежено: рішення приймають гравці.
Ресурси, зарплати, витрати, платежі, кар’єра та виконання Мрій обліковуються окремо.
Для Lounge, Академії та START показано пам’ятки, їхні правила застосовуються вручну.
Картки містять текстові умови й наслідки, без автоматичного застосування.
Позиції зберігаються лише до перезавантаження сторінки.
На вузькому екрані поле можна прокручувати горизонтально.

Файли: index.html, style.css, script.js, images/.
Для заміни попередньої версії оновіть усі три файли та папку images, а не лише JavaScript.
